# KERN Registro V11

Versão preparada para GitHub Pages.

## Ajustes desta versão
- Botão X do editor centralizado.
- Ao clicar em **Ajustar**, a página rola automaticamente até a grade de ajuste.
- O primeiro horário vazio recebe foco automaticamente.
- Mantém edição de status, horários, folgas, feriados e geração do PDF calculado.

## Executar localmente
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
